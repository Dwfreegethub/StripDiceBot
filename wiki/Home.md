# Strip Dice

A dice game for [Bondage Club](https://www.bondageprojects.com/club_game/), run by **StripDiceBot** in its own chat room. Players take turns rolling a shrinking die. Roll a 1 and you lose a piece of clothing. Once you're naked, every loss is a restraint instead. The last player still free wins, and everyone else stays locked up for a while.

You don't need to install anything. Walk into the room and type **`/bot help`**.

## What's New

* **`/bot` commands.** Type `/bot roll` instead of `!roll`: only the bot sees it, so the room isn't flooded with commands. The old `!` commands all still work.
* **A version number.** The bot's "online" line and `/bot about` show which version is running.

Type `/bot changelog` in the room for the latest changes.
